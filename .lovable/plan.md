## P-065 — PO detail enhancements, branded PDF, tokenized vendor share link

### 1. Migration `0027_po_share_and_pdf.sql`
- `create or replace function public.get_po_by_share_token(p_token uuid) returns table (…whitelist…) language sql stable security definer set search_path = public` — returns only: `id, po_number, status, currency_code, lines, subtotal, tax_pct, tax_amount, total_amount, payment_terms, incoterms, delivery_address, required_by_date, issued_at, pdf_path, vendor_name (join vendors), project_name (join projects), company_name, primary_color, accent_color, footer_text, logo_url`. Filter: `share_token = p_token AND share_token_expires_at IS NOT NULL AND share_token_expires_at > now() AND status <> 'cancelled'`. `revoke execute … from public`, then `grant execute … to anon, authenticated`.
- No table changes needed (share_token / share_token_expires_at / pdf_path already exist from `0026`).

### 2. Branded PO PDF builder — `src/lib/exports/po-pdf.ts`
- New pure module (mirrors `proposal-pdf.ts` / `kickoff-pdf.ts` style): `buildPoPdfBytes({ po, vendor, project, company, branding }): Promise<Uint8Array>`.
- Header band using `branding.primary_color` (fallback token-neutral `#1e40af`), embedded logo via `fetchLogoDataUrl`, PO number + status + currency.
- Vendor block, delivery block, lines table via `jspdf-autotable`, totals block (subtotal / tax / total), payment_terms / incoterms / required_by_date.
- Footer: `branding.footer_text || "Generated by GridMind EPC"`.
- Uses the shared `sanitize()` pattern from proposal-pdf that already strips `&;` / `&amp;` artifacts so "O&M", "C&I" render clean.

### 3. Server functions — extend `src/lib/po.functions.ts`
- `getPoBranding(context, companyId)` internal helper → row from `company_branding` + logo signed URL (60 min).
- Update `issuePo` handler: after status flip to `issued`, generate PDF via `buildPoPdfBytes`, upload to `documents` bucket at path `${company_id}/po/${po_id}.pdf` using the request-scoped `context.supabase.storage` (RLS-safe; first segment = company UUID satisfies existing `company_files_insert`/`select` policies), then `update purchase_orders set pdf_path = …`. Audit `po.issue` continues to fire; failure of PDF generation is caught, logged, and does not roll back the issue (status stays issued, `pdf_path` null, "Regenerate" button visible).
- New `regeneratePoPdf({ poId })` — role-gated (procurement_admin/officer, finance_admin, company_admin); rebuilds and re-uploads. Audit `po.pdf_regenerate`.
- New `getPoPdfDownloadUrl({ poId })` — returns short-lived (5 min) signed URL from `documents` bucket. Regenerates transparently if `pdf_path` missing.
- New `createPoShareLink({ poId })` — role-gated (procurement_admin/officer, company_admin); rotates `share_token = gen_random_uuid()`, sets `share_token_expires_at = now() + interval '14 days'`. Returns `{ token, expiresAt }`. Audit `po.share_link_create`.
- New `revokePoShareLink({ poId })` — sets `share_token_expires_at = now()`. Audit `po.share_link_revoke`.
- New unauthenticated `getPoByShareToken({ token })` — validates UUID, calls `context.supabase.rpc('get_po_by_share_token', { p_token: token })` via a request-scoped **publishable-key** client (no service role). Returns `{ status: 'ok', po }` or `{ status: 'expired' }` (HTTP 410) or `{ status: 'not_found' }` (404). When `pdf_path` present, mints a short signed URL via `supabaseAdmin` **only after** the DB row was found (admin scoped to just that pdf_path).

### 4. UI — `src/routes/_authenticated/procurement.pos.$poId.tsx`
Adds to existing page:
- **Status stepper** (`draft → pending_approval → approved → issued → partially_received → received → closed`, plus muted `cancelled`) using semantic tokens; current step `bg-primary`, completed `bg-primary/40`, upcoming `bg-muted`.
- **Approval trail card**: `approved_by` name (join `profiles.email`), `approved_at`, `approval_note`.
- **"Download PDF" button** — visible once `status ∈ (issued, partially_received, received, closed)`. Calls `getPoPdfDownloadUrl` then `window.open(url)`. Sibling "Regenerate PDF" when `pdf_path` is null.
- **Vendor share panel** (procurement roles only): shows current token expiry, "Create link" / "Regenerate" / "Revoke" actions, copy-to-clipboard of `${origin}/po/${token}`. Uses `useMutation` + sonner toasts, semantic tokens only.
- Loading via `useSuspenseQuery` + suspense fallback skeleton; existing `notFound()` / forbidden handling stays.

### 5. Query wiring — `src/lib/po-query.ts`
- `poPdfUrlMutation`, `createShareLinkMutation`, `revokeShareLinkMutation`, `regeneratePdfMutation` — all invalidate `["po", poId]`. Add `publicPoQueryOptions(fn, token)` for the public route.

### 6. Public read-only route — `src/routes/po.$token.tsx`
- Sits outside `_authenticated`. Uses `beforeLoad`/loader to call `getPoByShareToken`. `notFoundComponent` renders branded "Link expired" state (uses same `primary_color` if server returned partial branding on expiry — otherwise generic).
- Minimal shell (no sidebar): logo (company branding when available), PO number, status pill, vendor + delivery, lines table, totals, required_by_date, "Download PDF" button (opens signed URL from server response).
- SEO: unique `head()` — title `PO {po_number} — {company_name}`, `noindex, nofollow` meta.
- Never renders margin/cost internals — only whitelisted fields from the RPC.

### Notes / risks
- `jspdf` runs in the Cloudflare Worker runtime (already used server-side by `kickoff-pdf.ts` inside `opportunity.functions.ts`).
- `supabaseAdmin` used only for the *post-validation* signed URL mint on the public route, never for the row lookup itself — matches the security-note pattern.
- The SECURITY DEFINER function's `search_path = public` and column whitelist protect against schema drift leaking sensitive columns later.
